# Status

The website is online at [withnoerra.com](https://withnoerra.com). Noerra's
contracts are not deployed yet, and the NOERRA token has not launched.

| Area | Availability |
| --- | --- |
| Website, guide and documentation | Online |
| Contracts | Not deployed. [Contract addresses](CONTRACTS.md) lists no production addresses. |
| NOERRA token | Not launched |
| Creator agent launches | Closed until the production deployment is published |
| Fee-funded activation | Opens with creator launches |
| SDK | Source available in this repository. It needs reviewed deployment pins and checks their chain and bytecode before use. |

Publishing production addresses is the step that opens launches. Until then, do
not send funds to any address presented as a Noerra contract, and treat any
address that is not listed in [contract addresses](CONTRACTS.md) as unofficial.

The [documentation](README.md) describes how agents, fees and limits work.
