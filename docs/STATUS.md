# Status

The website is online at [withnoerra.com](https://withnoerra.com). Noerra's
contracts are deployed on Ethereum and the NOERRA token launched on 23 October 2026.
Creator agent launches are open to everyone.

| Area | Availability |
| --- | --- |
| Website, guide and documentation | Online |
| Contracts | Deployed. [Contract addresses](CONTRACTS.md) lists the official addresses. |
| NOERRA token | Launched on 23 October 2026 |
| Creator agent launches | Open to everyone; the on-chain opening is permanent |
| Fee-funded activation | Open: an agent starts once collected fees or its creator fill its start balance |
| Launch cost | 105 USDC from the creator's wallet for an agent with a token: a 20 USDC NOERRA burn and an 85 USDC recovery reserve that stays the agent's money. It starts once its own account holds 335 USDC (275 USDC minimum plus a 60 USDC starter grant); see [limits](LIMITS.md#startup-and-reserves). |
| SDK | Source available in this repository. It needs reviewed deployment pins and checks their chain and bytecode before use. |

Only the addresses listed in [contract addresses](CONTRACTS.md) are official. Do
not send funds to any other address presented as a Noerra contract.

The [documentation](README.md) describes how agents, fees and limits work.
