# Contracts

Solidity sources for Noerra agent accounts, token markets, funding, backing and recovery. Build with `npm run deps` followed by `npm run build:contracts`; run the contract suite with `npm run test:contracts`.

Published source is not a deployment record. Verify the chain, deployed address, bytecode and configuration before interacting with any market.
